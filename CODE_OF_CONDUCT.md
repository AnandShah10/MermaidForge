# Code of Conduct

This project follows the spirit of the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Our standard

Be kind, assume good faith, and keep discussion about the work. Welcome people of every background and experience level.

Unacceptable: harassment, insults, personal attacks, discriminatory language, publishing someone's private information, sustained disruption, and any conduct you would not accept in a professional setting.

## Scope

Issues, pull requests, discussions and any space where someone represents the project.

## Enforcement

Maintainers may edit or remove comments, close threads, and block contributors who break these rules. To report a problem, contact the maintainer, [Anand Shah](https://github.com/AnandShah10), through GitHub (a private security advisory or a message on the profile if you need privacy). Reports are handled confidentially.
