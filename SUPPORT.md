# Getting help

1. Read the [README](./README.md), [FEATURES.md](./FEATURES.md) and [LIMITATIONS.md](./LIMITATIONS.md) — many "bugs" are documented limits.
2. Look at *View → Output → MermaidForge* for errors.
3. Search [existing issues](https://github.com/AnandShah10/mermaidforge/issues).
4. Open a [new issue](https://github.com/AnandShah10/mermaidforge/issues/new/choose) with a minimal diagram or repo that reproduces it.

Security problems: see [SECURITY.md](./SECURITY.md), not a public issue.
